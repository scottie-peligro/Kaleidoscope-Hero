# Preset settings

The preset editor is organized into five sections. Every setting is retained; changing sections does not reset or save values.

| Section | What you adjust |
| --- | --- |
| Element | Animation on/off, element, speed, density and controls specific to the selected element. The element menu groups related looks. |
| Appearance | Palette, brightness, opacity and background colors. Glow, kaleidoscope, tessellation and blending have separate expandable sections, with active settings shown in their summaries. |
| Interaction | Mouse following, mouse-hold warp, particle or ribbon responses, automatic vortex and mouse-edge vortex. |
| Text & links | Built-in heading, subheading, button and navigation links. These controls are hidden in Section background mode, with an explanation of where to add page content instead. |
| Placement | Hero or Section background, relevant size/darkness controls and the shortcode identifier. |

**Apply or save a template** sits below these sections. It applies and saves the same reusable templates as before; use the Templates page for import/export and library management. Applying a template updates all sections, and Undo restores their previous values.

The preview stays alongside the controls on wide screens. On phones it starts collapsed, so the settings are easier to reach; expand Live preview when you need it. Preview and shortcode options can be collapsed on desktop too. Copy shortcodes, duplicate and delete remain available under the preview.

Save preset remains fixed at the bottom. An unsaved-changes indicator shows when the form differs from the loaded preset. All sections submit together, including controls that are currently hidden or collapsed. Existing presets, templates, shortcode names and frontend effects are unchanged.

Keyboard users can move between section tabs with Left/Right, Home and End. Invalid fields open their section and containing disclosure so validation is visible. If JavaScript is unavailable, all sections remain available in a continuous form.
