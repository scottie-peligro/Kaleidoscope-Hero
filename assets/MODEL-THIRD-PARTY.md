# Optional model importer

Built with Three.js 0.186.0 (`GLTFLoader`, `SVGLoader`, geometry utilities and `DRACOLoader`), MIT: https://github.com/mrdoob/three.js. See THREE-LICENSE.txt. This does not create a second WebGL rendering context.

Meshoptimizer's bundled decoder, MIT: https://github.com/zeux/meshoptimizer. See MESHOPT-LICENSE.txt.

Draco glTF decoder JavaScript/WebAssembly distributed with Three.js 0.186.0, Apache 2.0: https://github.com/google/draco. See model-draco/LICENSE.txt. The decoder downloads only when required by a GLB.

Build tooling is not needed in WordPress. Source and prebuilt bundles are included. The original crystal and SVG badge in models/ are dedicated to CC0; see models/LICENSE.txt.
